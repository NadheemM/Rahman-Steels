# Rahman Iron & Steel Shop Management System

## Project Structure
- **client**: React + Vite Frontend
- **server**: Node.js + Express Backend

## Prerequisites
- Node.js
- MongoDB (Local or Atlas)

## Getting Started

### 1. Setup Backend
```bash
cd server
npm install
# Create a .env file if not exists (already created)
npm run dev
```
Server runs on http://localhost:5000

### 2. Setup Frontend
```bash
cd client
npm install
npm run dev
```
Frontend runs on http://localhost:5173
